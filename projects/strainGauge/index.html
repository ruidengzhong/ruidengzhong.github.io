Strain Gauge PCB

Altium, PCB Assembly, Soldering, MoTeC M1 Tune

Project Overview

This project involved the design of a compact strain gauge signal-conditioning PCB using Altium Designer. The board accepts the low-level differential output from a strain gauge network, amplifies it with an instrumentation amplifier, and provides a conditioned analog signal suitable for measurement by a microcontroller, data-acquisition system, or oscilloscope.

Because strain gauges produce very small changes in voltage, the circuit was designed to provide high differential gain while maintaining a stable reference point for single-supply operation.

Circuit Design

The primary signal-conditioning device is an INA121 instrumentation amplifier. Its high input impedance and excellent common-mode rejection make it well suited for measuring the small differential voltage generated by a strain gauge bridge.

The amplifier gain is set using an external 100 Ω gain resistor. Based on the INA121 gain relationship, this produces a nominal gain of approximately 500 V/V, allowing small strain-induced voltage changes to be measured more easily.

The board operates from a single 5 V supply. Since the instrumentation amplifier is used with a single supply, a mid-supply reference is required. A pair of 1 kΩ resistors creates an approximately 2.5 V reference, which is buffered by a UA741 operational amplifier before being connected to the INA121 reference input. This allows the amplified output to be centered around the reference voltage rather than around ground.

The strain gauge input network uses fixed 1 kΩ resistors along with the external strain gauge connection to form the sensor measurement circuit. The conditioned output is routed to a three-pin connector providing:

  • 5 V supply
  • Analog signal output
  • Ground
  • PCB Layout
Schematic built in Altium

The schematic and printed circuit board were designed in Altium Designer. The PCB uses a two-layer layout with through-hole components and connectors. Component placement was organized around the INA121 to keep the sensor signal paths short and direct. The gain resistor was positioned close to the instrumentation amplifier to reduce unwanted interference and help maintain accurate gain control.

The board includes:

  • A dedicated three-pin strain gauge input connector
  • A three-pin conditioned signal output connector
  • INA121 instrumentation amplifier
  • External gain resistor
  • Buffered mid-supply reference circuit
  • Four grounded mounting points
  • Clearly labeled component references, connectors, power, signal, and ground connections Care was taken to separate the low-level strain gauge input routing from the output and reference circuitry. Grounded mounting points were also included at the corners of the board to provide mechanical support and convenient grounding locations.

Design Goals

The main goals of the design were to:

  • Amplify the small differential signal from a strain gauge
  • Provide high common-mode noise rejection
  • Operate from a single 5 V supply
  • Generate a stable mid-supply reference
  • Provide a simple interface for connecting the sensor and external measurement equipment
  • Create a compact, manufacturable PCB layout
  • Maintain clear and organized routing for future assembly and debugging
  • Skills Demonstrated

This project demonstrates experience with:

  • Analog circuit design
  • Strain gauge signal conditioning
  • Instrumentation amplifier applications
  • Single-supply reference generation
  • Schematic capture in Altium Designer
  • Two-layer PCB layout
  • Through-hole component placement
  • PCB routing and connector interfacing
  • Design-for-assembly and design-for-debug considerations

Project Outcome

The completed design provides a dedicated hardware interface for converting the small output of a strain gauge into a high-level analog voltage. The resulting PCB combines the sensor interface, high-gain differential amplification, reference generation, power connections, and output interface into a single compact board.
